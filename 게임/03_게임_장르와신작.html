게임 장르와 신작 — 검증된 IP·서바이벌·슈터로 쏠림, 2026 하반기 공백 뒤 2027년에 몰리지만 일정은 계속 밀림

결론

  • 신규 IP 흥행이 어려워 «검증된 IP·대형 프랜차이즈»로 쏠림 → GTA6도, 국내 신작 상당수도 기존 IP 확장 (NH, 11-16)
  • GTA6(11/19) «블랙홀»에 2026 하반기~2027년 1분기가 신작 공백 → 2027년 봄부터 출시 재개가 업계 공통 기대 (NH, 11-16)
  • 하지만 일정 신뢰도가 낮음: 테스트 후 개발 취소·서비스 종료가 잇따라 확정 출시일 전 신작 매출은 0으로 보는 하우스까지 등장 (신영, 10-13; 하나, 10-12)

② 장르 트렌드: 무엇이 뜨고 무엇이 식나

요약

  • 뜨는 쪽: 서바이벌·오픈월드 패키지, 배틀로얄의 «모드 확장», 저사양 모바일 배틀로얄, 리워드형 캐주얼, UGC
  • 식는 쪽: 국내 모바일 MMORPG(경쟁 과열), 신규 IP 슈터 테스트작(취소·종료 잇따름)
  • 바뀐 판: 게임스컴에서 중국 게임사 비중 급증, 연사 주제 대부분이 AI (현대차, 09-02)

MMORPG — 모바일에서 PC·클래식으로

  • 국내 모바일 MMORPG = 경쟁 과열: 기존 대표작들이 경쟁작 출시로 계속 하락, 리니지W는 3Q26 QoQ −23.3% (IBK, 11-11)
  • 흥행 공식이 이동: ① PC 동시 출시(아이온2 — 초기 일매출 50억·DAU 150만) ② 원작 재현 «클래식»(리니지 클래식 — 8개월 누적 4,278억) ③ 스팀 글로벌(아이온2 글로벌) (삼성, 2025-12-01; IBK, 11-11)
  • 초반 흥행 뒤 급감 문제: 아이온2 한국·대만은 멤버십 가격 인하·트래픽 감소로 3Q26 매출 526억 → 글로벌판 추정도 하향 (하나, 11-11)
  • 모바일은 «가벼운 과금 + 원작 IP»가 통함: 웹소설 IP 기반 도트 그래픽 2.5D MMORPG가 착한 과금 모델·공격적 마케팅으로 국내 구글 매출 1위 (삼성, 11-03)

슈터·배틀로얄 — 한 게임 안에서 장르 확장

  • 배틀로얄 PUBG의 트래픽은 스팀 슈팅 장르 2위권 → 배틀로얄에 머물지 않고 PvE 모드(제노포인트, 루트 슈터 로그라이트)·협업 모드(페이데이)·UGC를 붙여 이용자 폭을 넓힘 (교보, 06-30; 삼성, 05-04)
  • 새 PvE 모드가 기존 배틀로얄 트래픽을 잠식하지 않고 «순증» → 장르 확장이 통한다는 근거 (유안타, 06-30)
  • 신규 슈터 IP는 고전: 탑다운 슈터(블라인드스팟)는 무료 EA 후 서비스 종료, 익스트랙션 슈터(블랙버짓)는 높은 위시리스트 순위에도 개발 취소 (유진, 10-12; 신영, 10-13)

서바이벌·오픈월드 — 패키지 대흥행의 무대

  • 서브노티카2: 수중 서바이벌 어드벤처, 34주 연속 스팀 위시리스트 1위 → 5/15 PC·Xbox 게임패스 동시 EA → 22일 500만 장, 남은 위시리스트 445만 (삼성, 05-04; 유진, 11-11)
  • 팰월드: 정식 출시 최고 동접 96만 → 모바일판(오픈월드 서바이벌 슈팅) 기대로 연결 (삼성, 07-23)
  • GTA6(오픈월드 액션 어드벤처): 게임 안 숏폼·라이브 스트리밍 기능 반영 예정 → 업계가 출시일을 피해 신작을 미룰 만큼 영향력 큼 (NH, 11-16)

협동·인디·UGC — 작은 팀, 긴 꼬리

  • 2인 협동 퍼즐 장르: 고점 높고(It Takes Two 3천만 장+) 저점도 낮음 → 초기 입소문이 성패를 가름 (현대차, 09-02)
  • 퍼블리셔가 35명 규모 해외 소형 스튜디오까지 발굴 → 인디 협동작도 대형사 파이프라인에 들어옴 (현대차, 09-02)
  • UGC 플랫폼화: 배틀로얄 모바일에 크리에이터 보상 재화(WOW 토큰, 로블록스 로벅스와 비슷한 역할) 도입 + 로블록스 흥행작 IP 모드 출시 → 창작·소비 선순환 목표 (하나, 07-30)

캐주얼·리워드와 AI — 공급 폭증

  • AI로 모바일 캐주얼 게임 출시량이 크게 늘어 → 게임을 깔고 하면 보상을 주는 «리워드형 플랫폼»이 유리 (메리츠, 11-12)
  • 광고 플랫폼(앱러빈·유니티) 3Q 실적 서프라이즈, 광고주가 게임 외 소비재로 확대 (메리츠, 11-12)
  • 다른 쪽 AI: 게임 속 AI 동료·대화형 NPC(PUBG Ally 등), 대형사 AI 조직 150~170명 규모 (삼성, 2025-12-01)
  • 메리츠: «AI로 게임 ‘기업’의 장점이 희석, 더 많은 콘텐츠 공급으로 경쟁 심화» → 장르 불문 공급 과잉 위험 (메리츠, 11-12)

③ 신작 흥행을 읽는 법

요약

  • 출시 전: 위시리스트 → CBT·게임스컴 시연 반응 → 얼리액세스
  • 출시 후: 판매량(패키지) 또는 동접·매출 순위(부분유료) → 3개월 뒤 «얼마나 남나»가 진짜 성적
  • 테스트 단계 작품은 취소될 수 있음 → 확정 출시일 전에는 기대를 숫자로 넣지 않는 하우스가 늘어남

④ 신작 파이프라인 일정 (2026~2028)

요약

⑤ 흥행과 일정의 경제학

요약

  • 신작 한 편의 무게: 퍼블리싱작은 매출이 커도 이익 기여가 작고, 자체 개발작은 성공 시 레버리지가 큼
  • 출시 전 비용(게임스컴 마케팅·외주 개발)은 먼저 나가고 매출은 늦게 들어옴 → 일정이 밀리면 비용만 남는 구간이 생김
