05_게임_비용과수익구조

2026년 1월 01일30 min read

게임 비용과 수익구조 — 앱수수료는 줄고 외주·마케팅은 늘어남, 이익은 «라이브 이벤트 배치»가 결정

한눈에 보기

결론

  • 플랫폼 수수료는 내려가는 중: 구글 결제수수료 30% → 25%(2027-01), 대형사 자체결제 확산 → 매출 대비 5~10% 비용 절감 여지 (NH, 2026-11-16; 삼성, 2025-12-01)
  • 대신 비용의 무게중심이 «외주 개발비(지급수수료)»와 «성과 연동 마케팅비»로 이동 → 인건비 비중은 AI·구조조정으로 정체
  • 라이브 게임 이익은 콜라보·업데이트를 어느 분기에 넣느냐로 크게 흔들림 → 분기 실적 예측의 핵심 변수

① 기초: 게임사 비용 항목

요약

  • 게임사는 매출원가가 거의 없고(재고 없음) 비용 대부분이 판관비 → 인건비·지급수수료·앱수수료·마케팅비 4개가 몸통
  • «지급수수료»는 회사마다 내용이 다름: 외주 개발비, 개발사 몫(퍼블리셔일 때), 이스포츠 대회비 등
항목무엇매출과의 관계
인건비개발·운영 인력 급여·인센티브고정비 + 실적 연동 인센티브
주식보상비용스톡옵션·RSU 비용주가·부여 시점 따라 변동

자료: 교보(2026-11-11) 크래프톤 손익표 «매출원가 0, 판관비 = 영업비용», 교보(2026-06-30·10-06) 지급수수료 내용(외주 개발비·신규 프로젝트), 한화(2026-11-11) 이스포츠 대회 기저, 삼성(2026-11-03) 퍼블리셔 수수료

  • 크래프톤 손익표상 매출원가 0 → 매출총이익률 100% (교보, 2026-11-11)
  • 인센티브가 실적에 연동 → 실적이 빠지는 분기엔 인건비도 같이 줄어듦 (IBK, 2026-11-10; 유진, 2026-11-11)

② 사업모델별 비용구조 비교

요약

  • 자체개발 PC·모바일형은 인건비 20%대·마케팅 5% 미만으로 영업이익률 30% 안팎
  • MMORPG+모바일 캐주얼형은 캐주얼 확대로 마케팅비 비중이 7% → 35%로 급등(2025→2027E)
  • 퍼블리셔형은 지급수수료(개발사 몫)가 매출의 절반 → 흥행해도 영업이익률 한 자릿수~10%대

③ 플랫폼 수수료와 자체결제

요약

  • 구글 플레이 결제수수료가 2027-01부터 30% → 25%(앱스토어 20% + 결제 5%). 자체결제 사이트에도 적용, 외부 링크 허용
  • 대형사는 PC 런처·웹상점 자체결제를 2022년부터 순차 도입 → 결제수수료율이 내려오는 중
  • 모바일 매출 비중이 높고 자체결제를 늘리는 회사가 가장 큰 수혜

무엇인가

  • 구글이 2026-03 에픽게임즈와의 분쟁을 끝내며 발표한 플레이 스토어 수수료 개편. 하나였던 인앱결제 수수료(최대 30%)를 «앱마켓 서비스 수수료»와 «결제 처리 수수료»로 쪼갬 (SK, 2026-11-23)
  • 한국은 2026-12-31부터 적용 → 2027년 실적부터 반영 (SK, 2026-11-23)

원리(쉬운 말)

  • 장터 이용료(서비스 수수료)와 카드 결제 대행료(결제 처리 수수료)를 따로 받는 구조로 바뀜
  • 서비스 수수료는 «언제 설치한 이용자인가»와 «구글 Level Up 프로그램에 들었나»로 갈림 → 신작·신규 이용자일수록 낮음
  • 구글 결제를 쓰면 결제 처리 수수료가 별도로 붙음(미국·유럽 5%, 한국 요율 미확정)

왜 중요한가

  • 신규 설치 비중이 큰 신작 → 낮은 요율 / 기존 이용자 매출이 대부분인 장수 게임 → Level Up 참여 여부·기존 설치 요율이 관건 → 같은 회사라도 신작이 많을수록 절감 폭↑ (SK, 2026-11-23)
  • 절감분이 전부 영업이익이 되지는 않음 → 이용자 할인·마케팅 재투자, 외부 IP 게임은 개발사·퍼블리셔 계약대로 나눔 (SK, 2026-11-23)
  • 이미 직접 결제(DTC) 비중이 높은 회사는 추가 절감 여력↓: 소셜카지노 DTC 비중 3Q25 17.6% → 3Q26 53.6%, 1~3Q26 플랫폼 수수료 −18.4% YoY, 3Q26부터 일부 지역 구글 인하분 반영 (SK, 2026-11-23)
  • 애플은 방식이 다름: EU에서 인앱결제 26%·외부 결제 20%·외부 결제 링크 15%, 별도 앱마켓·웹 배포엔 CTC 5% → 지역 규제 대응형 (SK, 2026-11-23)

④ 인건비·외주·AI

요약

  • 2024~2025년 대형사·중견사 희망퇴직·조직 매각이 이어짐 → AI 도입으로 인력 조정이 빨라질 것이라는 전망 (삼성, 2025-12-01)
  • 인건비 대신 외주 개발비(지급수수료)가 커짐 → «사람을 줄이고 바깥에 맡기는» 구조로 이동
  • AI가 개발비를 낮춘다는 데는 공감, 그러나 공급 과잉으로 흥행 희소성이 떨어진다는 반론 존재

⑤ 마케팅과 라이브 운영

요약

  • 마케팅비는 신작·행사(게임스컴) 분기에 몰림. 대형사는 «효율 집행»이 실적 서프라이즈 요인
  • 라이브 게임 매출은 콜라보·대형 업데이트 배치로 분기마다 크게 흔들림 → 한 대형사의 분기 영업이익률이 2025~2026년 0%대~52% 사이를 오감
  • 신작 수명(PLC)은 장르·BM에 따라 9주 뒤 매출이 첫 주의 13%~100%로 갈림

  • 대형 MMORPG사는 3Q26 마케팅비를 적게 써 영업이익 컨센서스 12% 상회 → 마케팅 집행 시점이 분기 이익을 좌우 (메리츠·IBK, 2026-11-11~12)
  • 리워드형 플랫폼·모바일 캐주얼은 마케팅비가 매출과 같이 늘어나는 구조 → 영업이익률 하락을 감수한 외형 성장 (IBK, 2026-11-11; 메리츠, 2026-11-12)

라이브 운영: 이벤트 배치가 분기 실적을 결정

자료: 교보(2026-11-11) 크래프톤 분기 실적표. 2Q26 PC에는 신작(서브노티카2) 매출 약 2,000억원 포함(현대차, 2026-09-02)

자료: 교보(2026-11-11). 4Q25는 ADK 연결 편입 첫 분기라 이벤트 효과만으로 해석 못 함 ⚠

  • PC 매출: 슈퍼카·K팝 콜라보가 3분기 → 4분기로 옮겨가며 3Q26 PC −32.5% YoY, 4Q26 +25.7% YoY 추정 (교보, 2026-11-11)
  • 메리츠: «PUBG 성과는 이벤트 배치에 따라 분기 성과가 결정» → 3Q26 PC −37.2% YoY(교보 −32.5%와 차이, 넵튠·ADK 제외 기준으로 보임 ⚠) (메리츠, 2026-11-11)
  • 모바일은 1분기(춘절 프로모션) 성수기·4분기 비수기 패턴(중국판) (삼성, 2026-05-04; 현대차, 2026-09-02)
  • 라이브 운영 수단 = 웰메이드 모드·UGC·외부 IP 콜라보 → 비용은 지급수수료(외주)로 잡힘 (유안타·교보, 2026-07-30)

신작 수명(PLC)

자료: 삼성(2025-12-01) p.36 넷마블 신작 (그래프 판독, 근사)

  • 9주 뒤 매출이 첫 주의 13%(MMORPG)부터 99%(뱀피르)까지 → «출시 첫 달 매출 × 일정 배수»식 추정은 위험
  • 삼성은 «신작 흥행률 상승 + PLC 장기화»를 매출 반등 근거로 제시 (삼성, 2025-12-01)
  • PC MMORPG 사례: 출시 8개월 누적 4,278억원·일매출 18억원 유지 → 트래픽·구매 패턴 안정 시 PLC 장기화 (IBK·하나, 2026-11-11)
  • 반대 사례: 같은 해 출시 MMORPG는 멤버십 가격 인하·트래픽 감소로 매출 하락 (하나, 2026-11-11)

환율·회계: 2027년부터 영업이익에 외환손익

  • 퍼블리셔 정산을 받는 개발사는 매출 인식·정산 시차로 환 노출이 큼 → 3Q26 외환차손이 영업이익보다 컸던 회사 2곳 (메리츠, 2026-11-11)
  • IFRS-18 도입(2027) → 외환 관련 손익이 영업이익에 반영 → 이익 변동성 확대 (메리츠, 2026-11-11)
  • 해외 매출 비중이 작은 회사는 변동폭이 상대적으로 작음 (메리츠, 2026-11-12)
