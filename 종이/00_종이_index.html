결론

  • 수요는 물량 정체 + 지종 이동: 인쇄용지는 축소·재편, 성장은 포장(백판지·골판지)과 특수지(감열·라벨)
  • 이익은 시장 크기보다 원가(펄프·고지) − 판가 전가 − 환율·관세·운임의 차이가 정함 → 전가는 한두 분기 늦음
  • 2026년은 2Q 관세 환급으로 반짝 회복 → 3Q 환율 하락·중동전쟁 원가로 다시 적자. 버틴 지종은 고지 기반 백판지뿐

원천 한계

실제 원천 15건, 기간 2025-04-14~2026-11-13(2025년 6건·2026년 9건, 2024년 0건). 12건이 증권사 2곳(유진·흥국)의 1위 종합제지사 기업 리포트 → 1개사 숫자는 «업종 표본»으로만 씀. 산업물은 평가기관 3건(한국IR협의회·NICE·서울평가정보)뿐, 증권사 종이 산업 리포트 0건 ⚠. 캐시의 하나증권 «Korean Paper» 2건은 외화채물이라 제외. 제지연합회 물량 통계·국제 펄프 시세·백판지 업계 캐파 원천 없음 ⚠
