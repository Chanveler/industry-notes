05_우주항공_지상국과서비스

2026년 1월 01일32 min read

우주항공 지상국과 서비스 — 위성이 늘수록 «내려받는 길»이 병목, 돈은 지상 인프라 이용률과 데이터 활용 단계에서 남음

한눈에 보기

결론

  • 2025년 글로벌 우주경제 6,260억달러 중 위성활용 서비스 46.6%·지상장비와 위성운용 24.6% → 위성·발사체 제조(5.1%)보다 지상·서비스가 훨씬 큼 (교보, 2026-10-06)
  • 위성 수 급증 → 다운링크(지상 수신) 병목 → 지상국 공유 서비스(GSaaS)·LEO 게이트웨이·평판형 단말 수요 확대. 지상국 사업은 고정비 선투입 후 «이용률»이 이익을 결정
  • 데이터는 원천 영상 판매보다 정부 장기 조달·분석 서비스에서 가치 형성 → 국내 영상 판매 매출은 아직 분기 수십억원 수준
지표값시점출처
위성 브로드밴드 회선1,000만 → 3,300만2025 → 2031(IR협의회, 10-21)
지구관측 데이터·서비스 시장35억 → 79억유로2024 → 2034(IR협의회, 10-21)
글로벌 1위 지상국망 안테나170+ → 300+2018 → 2025(IR협의회, 10-21)
지상국 1기 연매출 잠재13~15억원2026(교보, 10-06)
국내 게이트웨이 수주잔고2,922억원2025 말(유안타, 05-06)

EO 시장 전망은 EUSPA, 회선 전망은 Ericsson 인용. 지상국 연매출 잠재는 하우스마다 다름(⑥)

① 기초: 지상 인프라와 서비스의 구조

요약

  • 우주산업 = 구축(Upstream) → 연결·운용(Midstream) → 활용(Downstream). 지상국·게이트웨이·안테나가 Midstream
  • 같은 «지상» 사업이라도 프로젝트형·인프라 운영형·서비스형으로 이익 구조가 완전히 다름

② 전방 수요: 위성 수·가입자·정부 조달

요약

  • 위성 발사 수는 2011~20년 대비 2021~31년 4.5배 → 지상에서 받아야 할 데이터·트래픽이 같이 늘어남
  • 정부 수요가 «위성 직접 구축 → 상업 데이터 구매 → 분석된 정보 구매»로 넘어가며 서비스형 사업의 첫 고객이 됨

③ 기술 심화

요약

  • 지상 쪽 핵심 기술 = 안테나(RF·광)·네트워크 운영 SW·영상 전처리. 위성 측 고도화(LEO·고해상도)가 지상 장비 사양을 끌어올림
  • LEO는 위성이 몇 분 만에 지나감 → 지상국 «분산 거점 수»와 단말의 «전자식 빔 전환»이 경쟁력

지상국 공유 서비스(GSaaS)

  • 원리: 위성이 사업자 지상국 상공을 지나는 시간을 예약 → 교신 횟수만큼 과금 → 같은 안테나를 여러 고객이 시간대별로 나눠 씀 (IR협의회, 2026-10-21)
  • 접속 간격: 단일 지상국 약 6시간 → 다국가 네트워크 약 20분 → 국방·재난 등 적시성 수요에 유리 (IR협의회, 2026-10-21; 교보, 2026-10-06)
  • 고객 잠금: 위성별 주파수·통신 규격 사전 연동 + 운용 이력 필요 → 한번 붙은 고객은 잘 안 떠남 (교보, 2026-10-06)
  • 고객이 직접 짓지 않는 이유: 국가별 주파수 인허가·설비투자·운영인력 부담 (IR협의회, 2026-10-21)
  • 예: 초소형위성 업체는 극지방 안테나가 많은 KSAT 안테나+AWS 클라우드를 임차해 운용 (IR협의회, 2026-10-21)

LEO 게이트웨이

  • 게이트웨이 = 지상 백본망 데이터를 위성으로 올리는 지상국 → 위성이 서비스 지역 단말로 분배 (교보, 2026-10-06)
  • 고도 450~550km LEO는 게이트웨이 1곳의 가시 범위가 좁음 → 망 규모·트래픽에 맞춰 수백 개 사이트 필요 (교보, 2026-10-06)
  • 스타링크: 2025년 125개 사이트·안테나 1,500개+ (교보, 2026-10-06) / 129개 지상국, 아시아·아프리카는 미비 (유안타, 2026-05-06)
  • 세대 교체·주파수 확장(Ku/Ka → Q/V → E 밴드) → 망 구축 후에도 게이트웨이 수요 반복 (유안타, 2026-05-06; 교보, 2026-10-06)
