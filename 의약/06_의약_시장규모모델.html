06_의약_시장규모모델

의약 시장규모 모델 — 에스테틱 수출 × 점유율 · CDMO 캐파 × 가동률 · 시밀러 · 기술수출 선급금

원천 한계

  • 의약 캐시 370건 중 2026년 335건·2025년 33건·2024년 2건 → 모델 숫자는 2025-05~2026-11 발간 23건에서 뽑음
  • 국내 처방·약가 시장 총액(원외처방 등)은 원천 1건뿐 ⚠ → 모델에서 뺌. 제약 내수는 04_의약_전통제약과유통 참고
  • 의료서비스·동물용의약품·의약품유통 중분류는 규모 숫자 원천 0건 ⚠
  • 바이오 CDMO는 삼성바이오로직스 1개사 표본(국내 항체 CDMO 캐파의 절반 이상), 셀트리온·롯데는 캐파 비교만
  • 2026년 국내 기술수출 연간 집계 원천 없음 ⚠ → 블록 D의 2026E는 비움

한눈에 보기

결론

  • 톡신·EBD 수출은 글로벌 시장(연 5~8%)보다 2~5배 빠르게 큼 → 2026E 톡신 수출 +38%는 시장 성장이 아니라 점유율 상승
  • 바이오 CDMO 표본 매출은 2027E 6.3조원(Base). 하우스 평균 6.2조는 5공장 상업화가 조금 늦는 경로와 비슷
  • 시밀러 2사 매출은 늘어도 글로벌 대비 7~8%에서 정체, 기술수출은 총액보다 선급금(약 5%)이 실제 현금

자료: 표 아래 출처와 같음. 십억원과 백만달러는 그래프를 나눔. 선급금은 2026E ⚠라 뺌, 톡신 점유는 표 참고

요약

  • 의약은 9단계로 나뉨: 신약개발·기술수출 → 원료의약품 → 바이오 CDMO → 전통제약·바이오시밀러 → 유통 → 에스테틱·덴탈·비미용 의료기기·의료서비스
  • 돈이 가장 많이 모이는 단계는 바이오시밀러(대표 2사 2025A 5.5조원)·바이오 CDMO(표본 4.6조원), 이익률이 가장 높은 단계는 에스테틱(1사 사례 40~50%)·바이오 CDMO(43~45%) → 전통제약은 5% 안팎
  • ⚠ 유통·동물용은 세 칸 모두, 덴탈은 시장 규모, 신약개발은 이익 원천 없음. 영업이익은 전 단계가 업계 합계가 아닌 1사 사례(덴탈만 3사 EBITDA)

신약개발·기술수출

  • 무엇을 파는 단계인가: 후보물질·플랫폼의 권리를 빅파마에 넘기고 선급금·마일스톤·로열티를 받음
  • 규모를 정하는 식: 건수 × 건당 총액 × 선급금 비중 → 총액은 대부분 조건부라 선급금이 실제 현금
  • 이익을 좌우하는 변수: 선급금 비중(국내 2~5% vs 글로벌 6%) · 마일스톤 달성률 · 임상 비용

원료의약품

  • 무엇을 파는 단계인가: 신약용 저분자 API·올리고(RNA 치료제 원료)를 수주 받아 생산
  • 규모를 정하는 식: 캐파(mol·kg) × 가동률 × 단가 → 상업화 품목 수가 가동률을 정함
  • 이익을 좌우하는 변수: 상업화 물량 비중 · 증설 뒤 감가상각 · 범용 API는 중국 대비 가격 열위
  • 올리고 CMO 캐파 글로벌 합산 약 13,000kg(2026E) (삼성, 2026-03-08), 올리고 수출 1~7월 1.97억달러(내 계산) (삼성, 2026-08-11)
  • 1사 사례(올리고 1위사): 2026E 전사 매출 4,146억원 중 올리고 2,810억원, 영업이익 709억원 → 전사 이익률 17.1%(내 계산) (삼성, 2026-03-08)
  • 다른 하우스는 같은 회사 2026E를 매출 4,413억원·영업이익 778억원(17.6%)으로 봄 (흥국, 2026-04-09)
  • 저분자 API 수주 사례: 1,077억원(2024-09) → 누적 2,600억원(2025) → 4,758억원(2026-10) (IBK, 2025-05-27 · IBK, 2025-11-04 · 메리츠, 2026-10-29)
  • ⚠ 없는 숫자: 글로벌·국내 API 시장 총액, 화학 합성 API 수출 통계, 올리고만 떼어 낸 영업이익

  • 무엇을 파는 단계인가: 항체 의약품 원액을 빅파마 대신 대량 생산(7~8년 장기 계약)
