06_전기전자_시장규모모델

2026년 1월 01일17 min read

전기전자 시장규모 모델 — MLCC(응용처 × 물량 × 판가) + PCB(유형별 물량 × 판가) + SoCAMM 기판 TAM

원천 한계

  • 전기전자 캐시 166건(2025년 6건 · 2026년 160건) → 모델 숫자는 2025-10-27~2026-11-19 발간 20건에서 뽑음
  • MLCC 시장 금액의 출발점은 iM 한 곳(2026-06-02 응용처별 추정) → 2025A 19.2조원 자체가 하우스 추정치 ⚠
  • 업계 «평균» 판가 원문 없음 → 삼성전기 블렌디드 ASP·유통/직납 인상폭에서 낮춰 잡음 ⚠
  • PCB 유형별 2024·2029 값은 키움(Prismark) 그래프 판독 → 합계만 본문 숫자와 일치시킴
  • 가전·TV·공조 시장 규모 원천은 기관 보고서 1건(GM Insights) + 회사 수주뿐 → 모델 밖 대조용

한눈에 보기

결론

  • MLCC 시장 Base 19.2조(2025A) → 29.0조원(2027E, +29%). 증가분의 절반 이상이 물량보다 범용 판가 — 범용 판가 10%p = 2.2조, 서버 판가 10%p = 0.35조
  • 서버 MLCC는 매출 비중 14%(27E)인데 이익 비중은 약 30% → AI 서버는 «매출 크기»보다 «이익 믹스» 변수
  • PCB 830억 달러(2025) → 1,110억 달러(2027E Base). Prismark가 2029년에 본 1,025억 달러를 Base는 2027년에 넘김 → 2024년식 경로는 이미 낡음

① 모델 구조·기초

요약

  • 블록 3개: A MLCC(조원) · B PCB(십억달러) · C SoCAMM 기판 TAM(억원) → A+B 합산 풀(조원)
  • 스위치 1개(Bear/Base/Bull)가 물량·판가·출하 배수를 함께 움직임 → 3안 전 수식(237개) 재계산 오류 0

⑥ 하우스별 시각과 검증

요약

  • 판가 눈높이가 하우스마다 다름: MLCC 27년 인상 SK 40~50% vs iM 30%(삼성전기 ASP) vs 모델 Base 15%(시장 평균)
  • 수요 성장도 «수량»과 «금액»이 섞여 숫자가 3배 차이(Taiyo 32% vs 키움 8~9%)
