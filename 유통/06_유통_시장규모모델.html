06_유통_시장규모모델

2026년 1월 01일36 min read

유통 시장규모 모델 — 방한객·내국인 × 1인당·점당 → 7개 업태 소매판매·이익 풀

한 줄: 국내 소매판매(승용차·연료 제외 521조원)를 7개 업태로 쪼개고, 백화점·면세는 «방한객 × 1인당 지출 + 내국인», 편의점은 «점포 × 점당 매출», 나머지는 성장률로 세움. Base 기준 2025A 521.1조원 → 2027E 554.7조원(연 +3.2%), 4개 업태 이익 풀은 2026E 4.3조원 → 2027E 4.8조원(+14%)

원천 한계

  • 텍스트 캐시 221건 중 2026년 217건, 2025년 4건 → 실제 원천 기간은 2025-11-19~2026-11-18. 모델 수치는 그중 업태 전망이 숫자로 있는 11건에서 뽑음
  • 업태별 판매액 정본은 국가데이터처 소매판매액(삼성증권 표 경유). 원문 통계 자체는 캐시에 없음 ⚠
  • 업태별 이익률은 업계 평균이 아니라 대표사 값(신세계 백화점·BGF·면세 3사·롯데 할인점)을 빌림 → 이익 풀은 상단 근사
  • 렌탈·홈쇼핑·무역·B2B·반도체유통·휴게소는 소매판매 업태 분류 밖 → 이 모델에 없음 ⚠ (본문은 05_유통_렌탈과기타)

한눈에 보기

결론

  • 판매액은 2027E +2.4%로 둔화 → 이익 풀은 +14%. 업태 성장보다 이익률 회복(백화점 총매출 이익률 5.4→5.8%, 면세 3.5→4.7%)이 이익을 끌고 감
  • 방한객 경로(미래에셋 2,394만 vs NH 2,600만)는 소매 총량을 1.2조원(0.2%)밖에 못 바꿈. 대신 면세 성장률을 −0.2% ↔ +6.5%로 뒤집음
  • 총량을 흔드는 건 무점포(1%p = 1.5조원)·전문소매(1%p = 2.0조원). 백화점 내국인 1%p는 0.4조원

비어 있는 곳

  • 사업자 순매출 합산: 백화점·대형마트·편의점·슈퍼 전부 없음 → 업태별 «상위 N사 순매출 합» 표가 있는 산업 리포트나 공시 합산이 있으면 채움
  • 업태 평균 이익률: 4업태 모두 대표사 값 대용 → 업계 통계나 N사 합산 이익률이 있으면 이익 풀 교체
  • 슈퍼·온라인·전문소매 이익: 이익 풀 없음 → 기업형 슈퍼 N사·이커머스 상위사·전문점(가전양판·H&B·균일가) 영업이익 합산 필요
  • 전문소매 세부 구성: 195.8조원 중 가전양판 12.1조원만 확인 → 국가데이터처 전문소매 세부 통계 필요
  • 홈쇼핑 매출·이익: 업계 합산 없음(사례 1~2곳) → TV홈쇼핑·T커머스 사업자 합산 실적, 송출수수료 업계 합계 필요
  • 렌탈: 시장 규모·매출 없음(1위사 매출 증가율 +11%와 이익률뿐) → 렌탈 산업 리포트(계정 수·해외 비중) 필요
  • B2B 유통·무역: 식자재·급식 시장 규모 없음, 종합상사는 트레이딩 마진 평시 1~2% (신한, 2026-04-07)뿐 → 식자재 시장 통계·상사 부문 합산 필요
  • 반도체유통·휴게소: 원천 0건 → 단계로 세우지 않음
