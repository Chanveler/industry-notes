방산 유도무기와 항공 — 요격탄이 모자란 세상, 천궁은 «싸고 빨리 오는 탄도탄 방어», KF-21은 «줄 안 서는 전투기»

결론

  • 두 전쟁(러-우·미-이란)이 요격탄 재고를 바닥냄 → 탄도탄 요격이 되는 체계는 Patriot·천궁-II·SAMP/T NG 정도뿐 → 2030년대 초중반까지 공급 부족 (한화, 2026-10-30)
  • 천궁-II = PAC-3 MSE의 약 1/4 가격 + UAE 실전 96% 요격 → 중동 3개국 수출 뒤 카타르·쿠웨이트·UAE 추가가 대기 (DS, 2026-05-28; 미래에셋, 2026-09-30)
  • 전투기는 서방 업체 잔고만 약 700대 → 신규 주문 시 2030년 전후 인도 → KF-21의 무기는 «납기». 첫 수출(인니)은 상대국 예산 승인만 남음 (한화, 2026-10-30·11-19)

① 기초: 방공은 «망», 탄도탄은 «고도»로 나눔

요약

  • 방공 = 센서(레이더) → 지휘통제 → 요격탄을 묶은 망(IAMD). 거리로 4층(VSHORAD~LRAD) 구분
  • 탄도탄 방어는 거리 대신 «요격 고도·비행 단계»로 구분 → 한국은 천궁-II(하층)·L-SAM(상층)·LAMD(저고도) 3단 구성 중

요격의 기본 원리

  • «2 on 1» 발사
    • 위협 1발에 요격탄 2발을 연속 발사하는 것이 표준 → 요격탄 소모가 위협 수의 2배 (유진, 2026-11-02)
  • Hit-to-Kill vs 파편형
    • PAC-3 MSE·L-SAM = 직접 충돌, GEM-T = 근접 폭발 파편형 → 탄도탄 대응력은 직접 충돌형이 우위 (한화, 2026-10-30; 유안타, 2026-09-15)
  • 공대공 미사일을 지상 발사로 바꾼 체계
    • NASAMS·IRIS-T SLM·VL-MICA는 항공기·순항미사일 중심 → 탄도탄 요격은 핵심 임무 아님 (유진, 2026-11-02)
    • 천궁은 Block-II에서 북한 단거리 탄도탄 대응을 넣어 하층 방어로 확장 (유진, 2026-11-02)

② 수요: 요격탄 소모 → 재고 재건

요약

  • 미-이란 전쟁 한 달여 만에 미국 Patriot 재고 56% 감소, 걸프 국가 요격탄 재고의 85% 소진
  • 포대를 산 뒤 요격탄 재장전 수요가 시차를 두고 따라옴 → 수요가 «체계 + 탄»으로 두 번 발생

  • Patriot 증산은 «포대»보다 «요격탄», 그것도 미국·기존 운용국 재고 재건이 먼저

④ K-방공 수출: 천궁-II → L-SAM → 저가 요격

요약

  • 천궁-II는 중동 3개국(UAE·사우디·이라크) 수출 + UAE 실전 요격으로 레퍼런스 확보

  • 유럽은 «탄도탄 방어 공백»이 기회지만 2026년 덴마크·스위스에서 연달아 탈락
