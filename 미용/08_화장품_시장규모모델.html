결론

  • 관세청 국가별 수출(HS 3304)을 바닥으로, 지역별 성장률 시나리오를 얹어 2028E까지 K뷰티 수출 파이를 그림
  • Base 수출 2025A 94.7억$ → 2028E 174.7억$, 늘어나는 몫의 절반 가까이를 유럽이 가져감
  • ODM·벤더 풀은 원문 근거 없는 가정(⚠)이 섞여 «규모 감» 용도로만 볼 것

① 모델 구조·기초

요약

  • 반도체 «캐파 → 비트 → 가격 → TAM» 구조를 «수출 → 성장률 → 소매가 배수 → TAM»으로 옮김
  • 기준 통계 = HS 3304. HS 33(헤드라인 숫자)은 1.206배로 환산

HS 33 = 산업부·KITA 발표, 뉴스 헤드라인 기준

  • 환산: 2025A HS 33 ÷ HS 3304 = 1.206배 → 2026E 이후에도 유지(Inputs!B53)
    • 헤어·바디·향수가 기초보다 빨리 크면 → HS 33 환산값 과소 추정 (NH투자증권, 2026-11-16)
  • 지역 정의 차이
    • 데이터북 «유럽»은 러시아 포함 → 신한(20개국, 러시아 제외)보다 큼
    • 데이터북 «북미» = 미국+캐나다 → 모델은 미국만 따로, 캐나다는 «기타»

  • 2026년 11~12월 확정치로 2026E를 실적으로 교체 (Model 2026E 수식 → Data 합계)
  • ⚠ 원문 없음 항목 메우기
    • 수출 벤더 전체 경유 비중(현재 20% 가정) — 벤더 상위사 매출 합계 ÷ 수출액으로 역산 가능한지
    • ODM 위탁 생산 비중(현재 80% 가정) — 식약처 생산실적·ODM 국내 매출 합계 ÷ 브랜드 매출로 교차 확인
    • 중국·일본·동남아·중동 K뷰티 채널 비중
    • 2026년 연평균 원/달러, 2028년 하우스 수출 전망
  • 2028E 하우스 전망이 나오면 감속 계수 대신 지역별 증가율 직접 입력
  • HS 33 ÷ HS 3304 배수가 2026년에 얼마로 바뀌었는지(헤어·바디 고성장 반영)
  • 유럽 침투율(2028E 13%, 7개국 분모) 과열 여부 — 러시아 분리 입력 검토

한 줄: 2026E는 10개월 실적으로 사실상 확정(Base 124.7억)이고, 2027E Base 151.0억는 하우스 범위 한가운데임. 믿을 것은 «유럽이 증가분 절반 가까이를 가져간다»는 방향, 의심할 것은 ODM·벤더 풀을 정하는 비율 가정(위탁 80%·경유 20%)
