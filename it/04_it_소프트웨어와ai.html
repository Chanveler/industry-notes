① 기초 — SW·AI는 다섯 층, 층마다 돈 버는 방식이 다름

요약

  • 모델 층은 «토큰 수량 × 단가», 응용 SW는 «좌석 × 구독료», IT서비스는 «인력 × 기간» 과금이 원래 구조
  • AI 에이전트가 사람 대신 일하면서 좌석·인력 기준 과금이 흔들림 → 사용량·성과 과금으로 이동 중

  • 고객의 모델 전환 유연성 «희망 90% vs 보유 10% 미만» → 멀티모델 오케스트레이션·평가 체계를 깔아주는 IT서비스 수요 (현대차, 2026-11-16)

② 전방 수요 — 누가 SW·AI에 돈을 쓰나

요약

  • 해외: 기업 AI는 «파일럿 → 확산»의 어수선한 중간. 개인 사용 90%, 손익 효과 본 기업 6~9% (02_IT_수요와전방 ②)
  • 그래도 에이전트 «사용량» 지표는 수십 배 단위로 늘어남 → 2027년은 에이전트 지출 +92%가 공통 기대
  • 국내: 공공·금융 AX가 앞장. 보안 사고가 금융권 AX를 앞당김

③ AI 모델 — 매출은 연산비를 넘었나

요약

  • 대표 모델사 분기 매출 0.4 → 17.0십억달러(1Q25 → 3Q26). 1Q26부터 매출 > 연산비
  • 2Q26 첫 영업흑자 → 3Q26 다시 소폭 적자(연산비 +77%) → «매출 성장과 수익성은 따로»가 공통 시각
  • 단가 하락(연 40배)·오픈웨이트(토큰 70%)가 모델 층 가격 결정력을 깎음

위로 가파른 선 = 매출, 다른 선 = 연산·인프라 비용(회사 분류). 자료: 앤트로픽 S-1/A, 미래에셋(2026-11-16) p.5

변수내용출처

  • 모델·API 전업 기업은 연산 조달비와 토큰 가격 경쟁에 동시 노출 → 수익화 경로가 다양한 빅테크보다 불리 (iM, 2026-11-19)
  • 단가 하락은 모델사엔 압박, 쓰는 기업엔 비용 절감 → 고객·데이터·업무흐름을 쥐고 절감분을 이익으로 남기는 쪽이 승자 (iM, 2026-11-19)
  • 모델이 비슷해지면 여러 모델을 함께 서빙하는 플랫폼(멀티모델 마켓)이 유리 (하나, 2026-10-30)

④ 응용 SW·SaaS — 잠식인가 확장인가

요약

  • 3Q26 미국 SW는 «AI 에이전트 수혜가 숫자로 나온 곳»(엣지·관측·데이터 운영)과 «아직 증명 중인 곳»(업무흐름·크리에이티브)으로 갈림
  • 시장은 매출보다 «선행지표(cRPO·TCV·가이던스)»에 반응 → 서프라이즈에도 −19% 급락 사례
  • 해자 = 컴플라이언스·제품 결정이 박힌 운영 SW. 위험 = 단순 기능 래퍼 앱, 프런티어 랩의 수직 진출

⑤ 보안과 IT서비스 — 구축에서 운영·관제로

요약

  • 보안: 에이전트 권한·딥페이크·OT가 새 공격면 → 국내 시장 연 10% 안팎, 대형 SI 보안은 +17%·OPM 17%
  • 단, 장비형 보안은 «AI 수혜 기대 > 실적»이라 성장 둔화 시 주가 −20%
  • SI: 구축(SI)·유지보수(ITO)는 역성장, 운영(MSP)·클라우드가 성장. 마진은 «계약이 얼마나 길게 이어지나»가 결정
