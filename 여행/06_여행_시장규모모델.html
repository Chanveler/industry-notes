여행 시장규모 모델 — 방한객·출국자 × 1인당·ASP·드롭 → 관광수입·패키지·카지노·호텔 4개 풀

한 줄: 업종 총액 원천이 없어 «물량 × 단가» 4개 풀을 따로 세움(합산 금지). Base 2027E 관광수입 48.5조원(+15%), 여행수지 −9억 달러(2028E 흑자 전환), 1위사 패키지 판매액 2.40조원(+7%), 외국인 카지노 3사 순매출 2.06조원(+3.5%)

원천 한계

  • 텍스트 캐시 135건(산업 86·기업 49) 중 2026년 119건, 2025년 16건 → 실제 원천 기간은 2025-04-14~2026-11-19. 모델 수치는 그중 숫자가 있는 12건에서 뽑음
  • 한국관광공사·한국은행 원 통계는 캐시에 없음 → 하우스 리포트 인용치 경유 ⚠
  • 패키지는 1위사 표본뿐(2위사는 3Q 분기 값만) → «업종 패키지 시장»이 아님 ⚠
  • 렌터카·여행플랫폼은 금액 원천 0건 → 이 모델에 없음 ⚠ (본문은 03_여행_여행사와플랫폼·05_여행_호텔과렌터카)

비어 있는 곳

  • 인바운드 관광 지출: 수요 총량이라 매출·이익 개념이 없음 → 업종별(숙박·쇼핑·카지노) 지출 분해 통계가 있으면 아래 단계 규모로 연결 가능
  • 여행사: 업계 전체 시장 규모·영업이익 합산 없음(대표 2사 수탁금·영업수익·이익률만) → 여행업 전체 거래액 통계, 2위사 연간 송객·ASP 필요
  • 여행플랫폼: 국내 OTA 거래액·점유율·수수료율 원천 0건 → 플랫폼 산업 리포트나 상위사 공시 필요
  • 내국인 카지노: 시장 규모(드롭·방문객) 시계열 없음, 매출·이익은 리조트 포함 연결 값 → 카지노 부문만 분리한 자료 필요
  • 호텔·리조트: 업계 매출·영업이익 없음(서울 4성 OCC 85%·ADR 20만원 한 시점, 필요 객실 수만 있음) → ADR·OCC 시계열과 객실 수가 있으면 «객실 × OCC × ADR» 금액 풀 가능
  • 렌터카·카셰어링: 시장 규모 없음 → 등록 대수·대당 매출 통계, 장기렌터카 산업 리포트 필요
