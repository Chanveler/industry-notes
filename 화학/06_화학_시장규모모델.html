06_화학_시장규모모델

2026년 1월 01일33 min read

화학 시장규모 모델 — 에틸렌 능력·가동률 × NCC 스프레드 → 국내 기초유분 시장·이익

한 줄: 국내 NCC를 «에틸렌 1,302만t짜리 설비 하나»로 놓고, 박스업·샤힌 증설로 물량을, 유안타 «NCC 손익 스프레드»로 단가·마진을 세움. Base 기준 기초유분 시장 2025A 29.9조원 → 2027E 30.2조원, 업황 이익은 −1.9조원 → 2026E +1.1조원(래깅) → 2027E −2.2조원으로 다시 적자

원천 한계

  • 텍스트 캐시 303건 중 2026년 289건, 2025년 14건 → 실제 원천 기간은 2025-03~2026-11-19
  • 4Q26은 10~11월 실측(유안타 11-17 월간 표) + 12월 같은 수준 가정. 2027E 환율·Dubai는 원유 시장규모모델의 하우스 값을 빌려 씀 ⚠
  • 가격 시계열은 유안타 Chemicals Monthly Data 원본 xlsx(주간, 2001~2026-09-04) 직접 집계 + 이후는 유안타 2026-11-17 월간 표

결론

  • 2025A 업황 이익 −1.9조원: 스프레드 188달러가 손익분기 230달러에 42달러 못 미침
  • 2026E는 4Q 스프레드 반등(10~11월 평균 288달러)과 래깅(+1.1조원)으로 +1.1조원 흑자 — 일회성 → 2027E Base 역래깅까지 겹쳐 −2.2조원
  • 흑자 조건은 스프레드 약 253달러 이상(역래깅 −23달러 감안). 박스업 315만t은 물량만 줄일 뿐 스프레드를 직접 올리지 못함

① 모델 구조·기초

요약

  • 원유 «처리량 × 크랙» 틀을 화학에선 «에틸렌 생산 × HVC 환산 × NCC 스프레드»로 옮김

② 물량 입력 — 능력·박스업·가동률

요약

  • 국내 에틸렌 능력 1,302만t(세계 약 5%) → 박스업 315만t·샤힌 +180만t → 2027E 연말 1,167만t(−10%)

  • 가동률은 2019~21년 89% → 2022~24년 76% → 2025년 82%. 2026년은 납사 차질로 2Q 급락

③ 단가 입력 — 스프레드·나프타·환율

요약

  • 스프레드 10년 평균 305달러 → 2022년부터 220달러 안팎 → 2025년 188달러로 하락 사이클 5년째
