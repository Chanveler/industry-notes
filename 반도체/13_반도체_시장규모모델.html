13_반도체_시장규모모델

2026년 1월 01일16 min read

반도체 시장규모 모델 — 밸류체인 10단계의 시장 규모·매출·영업이익 모음

원천 한계

  • 새로 계산한 모델이 아님 → 본문 노트 02~10과 원문 텍스트에 흩어진 숫자를 단계별로 모은 노트. 엑셀 모델은 메모리(범용 DRAM·HBM·NAND)만 있음
  • 영업이익은 어느 단계도 «업계 전체» 통계가 없음 → 대표 N사 합산·1위사 1곳·1사 사례로 채웠고 표의 «기준» 칸에 밝힘
  • 메모리 밖 단계는 시장 규모가 한두 시점뿐이고 조사기관마다 범위가 다름 → 단계끼리 금액을 더하면 안 됨 ⚠

한눈에 보기

결론 3줄

  • 돈이 가장 많이 모이는 단계는 메모리: DRAM+NAND 2,247억 달러(2025A) → 1조 3,415억 달러(2027E, Base) — 파운드리 1,839억 달러(2026E)·전공정 장비 2,000억 달러(2027E)를 크게 앞섬
  • 이익률이 확인되는 단계도 메모리(DRAM 78~80%·NAND 66~67%, 2Q26 대표 2사 추정)와 1위 파운드리(60.3%, 2Q26)뿐 → 장비·설비·부품은 일부 회사 합산이나 1사 사례 수준
  • 공정 소재·소모성 부품(A축)은 시장 규모·매출·영업이익이 모두 비어 있음 → 이 단계 기업을 볼 때는 물량 지표(웨이퍼 투입)만 쓸 수 있음
  • 메모리 캐파 → TAM 계산식과 3안은 04_메모리_증설로드맵 ⑤, 단계별 기술·수급 설명은 각 본문 노트 참고
  • 기업분석 아님: 회사 숫자는 «그 단계의 수익성 표본»으로만 씀

⓪ 밸류체인 단계별 규모·매출·영업이익 🆕 신규 11/24

요약

  • 규모: 메모리 DRAM 9,273억 달러·NAND 4,142억 달러(2027E, Base) ≫ 전공정 장비 2,000억 달러(2027E) ≒ 파운드리 1,839억 달러(2026E) ≫ 후공정 장비·기판·프로브카드(수십억~200억 달러대)
  • 수익성: 메모리 60~80%대·1위 파운드리 60% > 설비 1사 사례 15~23% → 장비·OSAT·부품소재는 이익률 원문이 거의 없음
  • 세 숫자가 다 채워진 단계는 10개 중 3개(DRAM·NAND·파운드리), 전공정 장비는 매출 대신 수주잔고만 있음 → 공정 소재·소모성 부품은 세 칸 모두 ⚠

메모리 시장 2027E = 자체 모델 Base(04 노트 ⑤), 메모리 «매출» = 조사기관 공급사 매출 합계 전망(TrendForce·대신 2026E)이라 시장과 같은 성격. 전공정 장비 «매출» 칸은 매출이 아니라 국내 증착 4사 합산 수주잔고, 영업이익은 국내 전공정 장비 6사 합산 분기값. 후공정 장비 = 테스트 + 패키징 장비 합(내 계산). OSAT 매출 = 상위 2사 컨센서스 합(내 계산). 설비 영업이익률 = 1사의 스크러버 17.4%·칠러 14.7%·용역 23.3%

비어 있는 곳

  • 메모리 DRAM·NAND: 제품별 연도 영업이익 없음(분기 추정치·한국 합산만) → 하우스의 제품별 손익 추정표가 있으면 채움
  • 파운드리: 시장 규모가 2026E 한 시점, 실적은 1위사 분기뿐 → 조사기관 연도별 시장과 상위 5사 실적 합산 필요
  • 팹리스: 영업이익(률) 없음, 시장도 2024·2030 두 시점뿐 → AI 가속기·ASIC 사업자 실적 합산 원천 필요
  • 전공정 장비: 업계 매출·영업이익 연도 표 없음(국내 6사 분기 영업이익 1점) → 글로벌 상위 5사 또는 국내 커버리지 합산 연간 전망 필요
  • 후공정 장비: 매출·영업이익 모두 없음 → 테스터·본더·핸들러 업체 합산 실적 원천 필요
  • 설비: 금액 시장 없음(Fab-in 물량·클린룸 1만 평 투자비 20조원만 있음) → 클린룸·CCSS·스크러버 품목별 시장 통계 필요
  • 부품소재 A축: 세 칸 모두 없음 → 웨이퍼·포토레지스트·전구체·특수가스·쿼츠 품목별 시장과 업체 합산 실적 필요
  • 부품소재 B축: 영업이익(률) 없음(판가 +10% → 영업이익률 약 +8%p 민감도만 있음), 프로브카드 30억 달러(2026)·테스트 소켓 21억 달러(2024)는 시점이 제각각 → 기판·소켓 업체 합산 실적 필요
  • 후공정 OSAT: 영업이익(률) 없음(원문에 그림만 있고 수치 없음) → 메모리·비메모리 OSAT 영업이익률 수치 필요
