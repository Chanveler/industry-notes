[반도체] AI 수요가 끄는 이번 메모리 사이클은 HBM이 웨이퍼를 잠식하고 신규 클린룸이 늦게 열리면서 공급 쪽이 사이클의 길이를 정하는 국면임

  • 이 문서 = 증권사 산업 리포트 6개월치(2026-05-19~11-18, 189건)로 만든 반도체 섹터 백과(노트 13개 + 메모리 캐파·TAM 엑셀 모델)의 «처음 읽는 사람용» 요약
  • 목적은 산업 이해 → 회사 이름은 «이 캐파·기술을 누가 들고 있나»의 사례로만 등장
  • ①→⑩ 순서로 읽고, 장 끝에 적힌 원 노트로 내려가면 됨

핵심 결론: 수요(AI 서버)는 2027년까지 공급보다 빠름 → 그런데 사이클의 «길이»는 수요보다 공급이 정함. HBM이 DRAM 웨이퍼의 25%(2026E)→35%(2027E)를 쓰면서 범용 DRAM 공급을 묶고, 신규 팹은 2027년에 장비가 들어가 2028년에야 웨이퍼가 나옴. 하우스 간 쟁점은 «언제 꺾이나»에서 «2H27~2028 조정이 얼마나 깊고, LTA·HBM이 얼마나 받쳐주나»로 이동함.

① 이 백과를 어떻게 읽나

  • 노트 한 장 = 중분류 하나, 모든 노트가 같은 7단 구조
    • ①기술 기초 → ②전방 수요 → ③기술 심화 → ④캐파·증설 → ⑤가격·수급 → ⑥하우스별 시각과 변화 → ⑦트래킹 포인트
    • 수요(②)를 먼저 알아야 기술 변화(③)가 «중요한 변화인지 단순 스펙 개선인지» 구분됨

② 전방 수요: AI CapEx가 무엇을 사나

  • 사슬 한 줄: 빅테크 CapEx → AI 서버 → 가속기(GPU·ASIC, 파운드리·CoWoS 필요) + 메모리(HBM·서버 DRAM·eSSD) → 메모리 증설 → 장비·설비·소재 발주
  • 비유: 빅테크 CapEx가 «주문서», 반도체 각 업종은 그 주문서가 내려가는 «하청 단계»

3) 약한 고리

  • 소비자 기기는 메모리 원가에 눌림
    • 스마트폰 메모리 원가율 10년 평균 11% → 3Q26 46%, 노트PC DRAM 원가율 3.7% → 25%
    • 2026년 스마트폰 −16%, PC −13%로 하향
  • AI 투자는 빚으로 메우기 시작함
    • 5대 하이퍼스케일러 2026년 회사채 발행 약 2,180억달러 = 2025년 연간의 두 배
    • 5대 하이퍼스케일러 합산 FCF 3Q26 −349억달러 = 2009년 이후 첫 적자
    • 반론: 부족분을 전부 차입해도 오라클 제외 4사 순차입금/EBITDA 1.2배 이하 → 약한 고리는 네오클라우드
  • 사양 축소(De-spec)
    • Rubin Ultra HBM 1,024GB 원안 → 384~512GB 축소안 → 8단 HBM4 2Q27 양산 목표
    • 다수 해석: 수요 감소가 아니라 메모리 공급 부족의 증거(공급 개선 시 Re-spec 가능)
    • 소수 해석: 수요 탄력 둔화 신호(BNK)

1) 메모리 기술

용어쉬운 말산업에 주는 영향
DRAM 세대(1b·1c·1d)10나노급 DRAM의 5·6·7세대 이름. 1c = HBM4·HBM4E 코어다이 공정1b→1c 선폭 축소폭 10% 미만 → 미세화로 얻는 비트가 줄어 증설 의존도 상승. DRAM 내 1c 비중 1.3%(2025) → 14.8%(2026) → 33.9%(2027)
EUV13.5nm 극자외선으로 회로를 한 번에 그리는 노광없으면 여러 번 겹쳐 그려야 함(멀티패터닝) → CXMT가 EUV 없이 1b급을 만드는 대가 = 공정 단계·원가 증가
6F² → 4F²트랜지스터를 세워 셀 면적을 줄이는 차세대 구조셀 면적 약 33% 축소 이론치. 웨이퍼당 장비 투자액 D1a 대비 1.8배(근사)
HBMDRAM 칩을 아파트처럼 쌓아 GPU 옆에 붙인 메모리같은 비트에 범용 대비 웨이퍼 3배(HBM3E)~4.5~5배(HBM4E) 소모 → 범용 공급 잠식의 원인
TSV칩에 수직 구멍을 뚫어 층을 잇는 전극«TSV 캐파» = HBM 생산능력의 대용치
베이스다이HBM 맨 아래 교통정리 칩. HBM4부터 파운드리 로직 공정4nm 전환 시 스택 전력 40% 감소. 대신 HBM 공급이 DRAM 웨이퍼 + 파운드리 캐파 «두 제약»에 동시에 묶임
커스텀 HBM(cHBM)고객이 베이스다이를 맞춤 설계적층 후엔 그 고객 외 팔 곳 없음 → 현물·유통 재고가 안 생겨 사이클 진폭 축소
MR-MUF / TC-NCF다 쌓은 뒤 액상 수지로 한꺼번에 채움(SK하이닉스) / 층마다 필름을 깔고 열압착(삼성·마이크론)MR-MUF는 16단 HBM4까지 유지, TC-NCF는 필름이 열을 가두는 한계
하이브리드 본딩범프 없이 구리끼리 직접 접합열저항 20%↓. 단 1μm 파티클 하나가 약 10mm² 불량 유발. JEDEC이 높이 기준을 720→775μm로 완화 → HBM 도입은 HBM4E~HBM5 전후로 늦춰짐
3D NAND 적층셀을 수백 층 위로 쌓음적층으로 비트 1% 늘릴 때 원가는 0.24%만 하락 → 단수 경쟁에서 «본딩·수평 미세화»로 무게 이동
SLC~QLC셀 하나에 1~4비트 저장QLC = 용량당 원가 최저. eSSD 내 QLC 비중 약 30%(2026) → 50% 이상(2027)
eSSD·KV 캐시AI가 대화 맥락을 기억하는 중간값을 SSD로 내려 저장100만 토큰 처리 캐시 = Rubin NVL72 GPU당 HBM 용량의 7배 → eSSD 수요 급증
SOCAMM2저전력 DRAM(LPDDR)을 묶은 서버용 모듈RDIMM 대비 면적·전력 약 1/3. 서버가 모바일·PC와 같은 LPDDR 물량을 두고 경쟁

④ 공급: 캐파·증설 로드맵

  • 캐파 숫자 읽는 법
    • 단위 = 월 웨이퍼 투입(K/월, 12인치 환산)
    • 투입 → 출하 5~6개월 시차, 착공 → 웨이퍼 생산 약 3년 반
    • 설계 캐파 ≠ 연말 캐파 → 용인 Y1은 최대 300K급 설계지만 2027년 말 캐파는 40K 추정
  • 비트 공급 = 웨이퍼 × 웨이퍼당 비트 → 공정 전환만으로도 비트는 늘어남(2026년 NAND 웨이퍼는 1,371K → 1,329K로 줄었는데 비트 공급은 +19%)

4) NAND와 중국

  • NAND 캐파 1,329K(2026) → 1,431K(2027, +8%) → 증설은 YMTC(200→270K)·솔리다임 정도, 나머지는 공정 전환

  • 신규 NAND 라인 가동은 2029년 이후 가능성 → 2027년 NAND CapEx는 +27%인데 캐파는 거의 안 늘어남(고단화 투자)

  • CXMT: DRAM 캐파 점유율 14%대 유지, 매출 점유율은 8%(2Q26) → 웨이퍼당 비트가 선두의 약 1/4~60% 수준

    • 회사 목표(2027년 말 420K)가 실현되면 2028E 점유율 17~20%대 ⚠

2) 계산 흐름

  • 연평균 캐파 = (전년 말 + 당해 말) ÷ 2 → 제품별(범용 DRAM = DRAM 전체 − HBM 배정분, HBM, NAND)
  • → × 웨이퍼당 비트 지수(1c·고단화 전환 반영, 2025 = 1)
  • → 비트 공급 지수
  • → × 가격 지수(시나리오별)
  • → × 2025A 매출 = 제품별 산업 TAM
  • → 업체별 캐파 점유율(CXMT는 웨이퍼당 매출 계수 0.53)로 배분
